# Omniboost Tap

## How do I install these formulae?

`brew install omniboost/tap/<formula>`

Or `brew tap omniboost/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "omniboost/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
